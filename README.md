# Pirate-Squabble
This is a web version of the classic game "BattleShip". The game is traditionally played on four grids, two for each player. The grids are typically square, usually 10 * 10, and the individual squares in the grid are Identified by letter and number. On one grid the player arranges the ships and records the shots by opponent. On the other grid, the player records their own shots. 

Before play begins, each player secretely arranges their ships. Check out more details about game [here](https://en.wikipedia.org/wiki/Battleship_(game)#:~:text=Descriptionedit)
